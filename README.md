# 🚀 AI Job Recovery Assistant

An AI-powered job recommendation system that analyzes user skills and resumes to recommend suitable tech roles.

---

## ✨ Features

- 📄 Resume Upload (PDF)
- 🧠 Smart Skill Detection
- 🎯 Job Match Percentage
- 📊 Match Visualization Charts
- ⚠️ Missing Skills Analysis
- 📌 Recommended Skills to Learn
- 💼 Multiple Job Recommendations

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- PyMuPDF

---

## ▶️ Run Project

```bash
streamlit run app.py
```
